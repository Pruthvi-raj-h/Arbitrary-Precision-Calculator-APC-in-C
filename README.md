# Arbitrary-Precision-Calculator-APC-in-C
Arbitrary Precision Calculator (APC) in C performs arithmetic operations on very large numbers beyond standard C data type limits using doubly linked lists and dynamic memory allocation. Supports addition, subtraction, multiplication, and division while demonstrating DSA, pointers, and modular programming concepts.
# Arbitrary Precision Calculator (APC) in C

## Objective
To develop an Arbitrary Precision Calculator capable of performing arithmetic operations on very large numbers that cannot be handled using standard C data types.

## Technologies Used
- C Programming
- Data Structures
- Doubly Linked Lists
- Dynamic Memory Allocation
- Modular Programming
- Command Line Arguments

## What is Arbitrary Precision Calculation
Arbitrary Precision Calculation is a technique used to perform mathematical operations on extremely large numbers with precision beyond the limits of built-in data types.

## Features
- Addition of large numbers
- Subtraction of very large numbers
- Multiplication of huge integers
- Division operation support
- Handles numbers beyond integer limits
- Uses doubly linked lists for storage

## Supported Operations
- `+` : Addition
- `-` : Subtraction
- `x` : Multiplication
- `/` : Division

## Compilation
```bash
gcc *.c -o apc
```

## Run

### Addition
```bash
./apc 999999999999 + 111111111111
```

### Subtraction
```bash
./apc 999999999999 - 111111111111
```

### Multiplication
```bash
./apc 99999 x 99999
```

### Division
```bash
./apc 999999 / 111
```

## Concepts Used
- Doubly Linked Lists
- Dynamic Memory Allocation
- Pointer Manipulation
- Command Line Arguments
- Large Number Arithmetic
